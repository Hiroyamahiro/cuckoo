# Cuckoo v2.0.1

- インストーラーを独自UIに刷新しました。更新時も設定・プリセット・追加音源を引き継ぎます。
- 新しい正式版をアプリ内で確認・ダウンロードできるようになりました。照合後、確認画面から更新できます。
- タイトルバーを簡素化し、ミニマム表示への切り替えとトレイ操作を調整しました。
- 「一括設定」から、00分・30分の時報を個別にまとめて設定できます。
- 英数字フォントUrbanistを同梱し、オフラインでも使用できるようにしました。
- 第三者ライセンス全文を1つの文書にまとめ、メニューや試聴ボタンなどの表示を整えました。

v2.0.0が起動中の場合は、トレイの「終了」から終了してから更新してください。
