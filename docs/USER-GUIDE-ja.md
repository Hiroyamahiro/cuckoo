# Cuckoo 2.1.0

製作者：ひろやまひろし / Hiroyama Hiroshi

## インストール

Windows x64向けです。独自セットアップEXEを起動し、「インストール」（既存版は「更新」）を押してください。
完了後の「Cuckooを起動」からアプリを開けます。
標準では現在のユーザーの LocalAppData/Programs/HiroyamaHiroshi/Cuckoo に入ります。
スタートメニュー直下の Cuckoo ショートカットから起動します。
スタートメニューへの登録は自動で行い、フォルダーの選択画面は表示しません。
既存の同名デスクトップショートカットは上書きしません。

WebView2が未導入の場合は、同梱Microsoftブートストラッパーが導入します。
この場合はインターネット接続が必要です。

## 利用

時計盤で00分・30分の時報を設定します。音色と1回／2回は個別に選べます。
学校チャイムの2回設定は、長い版を1回再生します。
追加音源はMP3、25MiB・60秒以下、100件までです。
プリセットには時計盤48枠のON/OFFだけを保存します。
時計下の「一括設定」から、00分・30分それぞれに「日中」「すべて」を適用できます。日中は09:00〜18:00の範囲で、もう一方の設定には影響しません。「すべてOFF」は両方を無効にします。
現在時刻のクリックで通常表示とミニマム表示を切り替えられます。
×、またはアプリメニューの「タスクトレイに格納」でトレイへ格納し、完全終了はトレイの「終了」から行います。

### カスタム時報（開発中）

「時報の追加」の「＋ 追加」から、00:00〜23:59の時刻・音色・1回／2回・個別音量を指定できます。同じ時刻は重複登録できません。一覧の時刻を押すと編集でき、チェックで有効／無効、削除ボタンで解除します。
カスタム時報が登録されていると、時計の最外周に点線の円を表示します。各点は24時間の文字盤上の登録時刻に対応し、有効な時報を針と同じ赤色で示します。全件OFFでも円と登録点を表示します。
外周の登録点をクリックすると、その時報をON／OFFにできます。ホバー時は点の上に時刻と状態を表示します。登録が0件になると外周を非表示にします。
時刻入力の時・分をクリックすると2列のホイールが開きます。それぞれ独立してスクロール・ドラッグ・上下キーで変更でき、数字をクリックして選ぶこともできます。領域外のクリックやEscで閉じます。「試聴」では編集中の音色・回数・個別音量を使用します。

「全体の音量」は共通のマスター音量です。00分・30分・カスタム時報の実際の音量は「全体の音量 × 個別音量」になります。既存設定の全体音量は維持し、個別音量は100%から開始します。
同時刻の既存時報とカスタム時報は順番に再生します。スリープ中に過ぎた時報はまとめて再生せず、復帰後の次回から再開します。プリセットと「一括設定」は従来どおり時計盤48枠だけを対象とします。

## 設定・アップデート

### VOICEVOX音声時報

「時報の音色」の00分・30分ボタン、またはカスタム時報の時刻ボタンから、共通の編集画面を開きます。音色で「音声読み上げ（VOICEVOX）」を選び、キャラクター・スタイル・読み上げモード・セリフを指定します。接続先が提供する読み上げ用の声を自動取得し、名前で検索できます。「一覧を更新」で追加された声も反映します。個別音量も同じ編集画面で設定します。

00分・30分の読み上げは、全24時刻の音声を事前に用意します。生成中は進捗を表示し、すべて成功してからまとめて保存します。自由セリフのみの場合は同じ音声を共用します。編集画面や一覧の試聴は、現在の時間帯の00分／30分を読み上げます。

初めて読み上げを設定するときは、別途導入したVOICEVOXまたはVOICEVOX Engineを起動してください。標準の`http://127.0.0.1:50021`に接続し、「試聴」または「保存」で必要な音声を自動生成します。準備中は進捗を表示し、失敗時は同じ操作から再試行できます。自由セリフは500文字以内、生成音声は60秒以内です。

読み上げの再生回数は1回固定で、回数の選択欄は表示しません。通常のチャイムは1回／2回を選択できます。生成済みの時報はVOICEVOXを終了しても再生できます。時刻（時刻を読むモードのみ）・キャラクター・読み上げ内容が変わった場合だけ新しい音声が必要です。音量・有効状態の変更で再合成しません。同じ条件はキャッシュを再利用します。失敗しても保存済み設定や音声は維持します。

生成音声は設定フォルダー内の`voicevox`に保存します。設定・バックアップ・編集中・再生中の音声を保護し、未参照と確認した日時から7日経過した音声を次回の整理時に回収します。整理は設定読み込み後・保存後・新規生成時に実行し、Engineは不要です。古い一時ファイルも回収します。キャッシュの上限は1GBで、保存時には別途一時領域の空きも確認します。設定や管理情報を読めない場合は削除を見送り、管理情報が破損していた場合は保管して猶予期間を最初から数え直します。VOICEVOX Engine・モデル・キャラクター画像は同梱していません。

未接続時は、公式ダウンロードページ・再接続・キャンセルの案内を表示します。接続失敗は未インストールの断定ではありません。インストール済みの場合はVOICEVOXを起動してください。選択していた声がなくなっても別の声へ自動変更しません。旧設定の2名の識別子とキャッシュは互換用として保持し、再選択した声はUUIDとスタイルIDで保存します。スタイルを変えると別のキャッシュになります。

利用条件：[VOICEVOX](https://voicevox.hiroshiba.jp/term/)および各音声ライブラリの規約に従ってください。編集画面では取得済み情報に基づく正式なクレジット表記と「利用規約」リンクを確認できます。表記やURLを特定できない場合は推測で補いません。Engineから取得した規約の案内は設定と一緒に保存し、「ライセンス・クレジット」でもオフライン閲覧できます。キャラクター選択の小さな画像はEngineから必要に応じて取得し、アプリ起動中のメモリーにキャッシュします。画像やモデルをパッケージには同梱しません。旧設定には従来の公式規約URLを使用します。生成音声をアプリ外で利用する場合も各規約とクレジット条件に従ってください。

正式版の設定と追加音源は LocalAppData/jp.hiroyamahiroshi.cuckoo に保存します。
開発版・Electron版の設定は読まず、新しい領域から開始します。
今後の正式版アップデートは同じ識別子と保存先を維持します。
新しいセットアップEXEで更新しても、設定を引き継ぎます。

新しい正式版があると、左上のアプリアイコン右上に小さな点が表示されます。
メニューの「更新する vX.X.X」を押すと、公式GitHub Releasesからインストーラーを取得し、SHA-256を照合します。
進捗と失敗時の案内はメニュー内に表示します。ダウンロードは中止でき、失敗後は同じメニューから再試行できます。
自動確認は起動時と約24時間ごとです。通信できない場合の自動通知は行いません。

インストーラーの「Cuckooを終了して更新します」を確認し、「終了して更新」で承認してください。
トレイ格納中も正常終了を要求し、プロセス終了を確認してから更新します。終了を確認できなければ更新を保留し、強制終了しません。
更新後は設定・プリセット・追加音源を保持してCuckooを再起動します。再起動に失敗した場合はインストーラーから再試行できます。
v2.0.0には外部からの正常終了要求への対応がないため、起動中のv2.0.0はトレイの「終了」から手動終了して再試行してください。

Windowsの「インストールされているアプリ」からCuckooをアンインストールできます。
独自の保守画面で確認して削除します。通常は設定と追加した音源を保持します。
データも削除する場合だけ「設定と追加した音源も削除する」を選択し、追加の確認に同意してください。削除は元に戻せません。
開発版・Electron版のデータは削除しません。
旧版と同時に時報を有効にすると、双方がそれぞれ再生するため、利用する側だけを有効にしてください。
