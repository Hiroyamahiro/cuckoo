# Cuckoo v2.1.0

- VOICEVOXの声で時報を読み上げられるようになりました。キャラクター・スタイルを選び、時刻や自由なセリフを設定できます。
- 00分・30分の時報と、1分単位で追加できるカスタム時報を共通の編集画面で設定できます。
- 時報ごとの音量と全体音量を調整できます。カスタム時報はダイヤルからクリック・ドラッグでON／OFFできます。
- 音声選択、利用規約・クレジット表示、ダイヤル、音色の登録解除画面を整えました。

音声の初回生成には、別途VOICEVOXまたはVOICEVOX Engineの導入・起動が必要です。生成済み音声は、VOICEVOXを終了しても再生できます。CuckooにVOICEVOX本体・音声モデル・キャラクター画像は同梱していません。

既存の設定・追加音源・生成済み音声は引き続き利用できます。
