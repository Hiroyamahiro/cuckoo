# Tabler Icons

Locally bundled outline SVGs from https://github.com/tabler/tabler-icons (MIT).
See LICENSE in this directory. Retrieved 2026-10-17; no runtime network access.

Cuckoo clock uses `canary.svg`; school chime uses `school-bell.svg`.
These two SVGs are from upstream commit
`a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d` (`icons/outline/`).
Church and custom audio use `building-church.svg` and `music.svg`.
The bulk settings button uses `adjustments-horizontal.svg` from the same
upstream commit listed above.
The pendulum clock uses the local `../pendulum-clock.svg`.
Rendering sets stroke-width to 1.75 and size to 18px. All icons use currentColor
and are decorative; labels supply names.

App menu icons: palette, photo, arrows-minimize, refresh, arrow-bar-to-down, copyright.
These also use upstream commit a4ce1404bc6d24d3c365afe7b258d6bf6f48d62d.

The volume slider uses volume.svg (same upstream commit); section headings have no icons.
The volume slider icon renders at 20px, stroke-width 1.75, using currentColor.
