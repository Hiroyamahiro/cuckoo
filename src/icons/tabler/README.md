# Tabler Icons

Locally bundled outline SVGs from https://github.com/tabler/tabler-icons (MIT).
See LICENSE in this directory. Retrieved 2026-10-17; no runtime network access.

The bird silhouette uses `brand-twitter.svg`; church, clock, bell and music use
their corresponding outline icons. Rendering sets stroke-width to 1.75 and size
to 18px. All icons use currentColor and are decorative; labels supply names.
